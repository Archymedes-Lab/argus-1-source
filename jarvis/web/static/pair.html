Pair this browser with ARGUS-1

ARGUS-1 could not confirm which account this browser runs under, so it will not show your security data until you pair it. On the machine running ARGUS-1, run jarvis desktop pair --name browser (if ARGUS-1 runs under its own account: sudo jarvis-svc desktop pair --name browser) and paste the token it prints.

The token is kept by this browser as a cookie that page scripts cannot read. You can list and revoke paired clients with jarvis desktop clients and jarvis desktop revoke ID.
