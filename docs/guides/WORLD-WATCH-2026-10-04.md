# World watch: reported conflict on a 3D globe, design record (2026-10-04)

State: built and tested in the checkout. Not staged, not deployed. The running daemon does not
have it until the owner deploys a release (see [the deploy guide](DEPLOY.md)).

## What it is

`/world` is a three.js heads-up-display globe of where armed conflict is being reported. A new
scheduled job, `world` (every 15 minutes), reads public newsroom feeds and GDELT, keeps the
reports about armed conflict, places them, and outlines where they cluster. The page shows a dot
per reported place, a card of what is being reported there on hover, outlined zones, a search over
the collected reports, a 72 hour timeline that can be replayed, and the distance from this device
(or a trusted zone) to the nearest zone. It is linked from `/geo`.

It is context for the owner. It raises no finding above `low`, is unscored, and is deferrable.
It is not in `jarvis/core/assurance.py`: it protects nothing and claims nothing about this machine.

## Files

- `jarvis/intel/worldwatch.py`: sources, parsing, conflict lexicon, gazetteer matching, zones, store.
- `jarvis/intel/data/gazetteer.json`, `jarvis/web/static/vendor/world-50m.json`: generated by
  `scripts/tools/build_world_assets.py` from three Natural Earth v5.1.2 files, each checked against
  a pinned SHA-256. The map file is served only if it matches its own pin.
- `jarvis/web/static/world.html`, `world.js`; routes in `jarvis/web/server.py` (`/world`,
  `/api/world`); job wiring in `service/jobs.py`, `service/schedule.py`, `core/governor.py`,
  `response/reporting/score.py`; `jarvis geo world [--refresh]`.
- `tests/test_worldwatch.py` (52 tests); `scripts/reviews/world_view_design.py`.

## Invariants, and the test that holds each

| Invariant | Held by |
|---|---|
| A report is placed only where its own words, or its publisher, put it; the precision (city, region, country) travels with it; otherwise it is listed as unmapped | `GazetteerTests`, `FeedParsingTests` |
| A place that is only speaking ("Moscow says") is not where it happened | `test_a_speaking_capital_is_not_where_it_happened` |
| A zone needs 5 located reports from 3 publishers, 2 of them a newsroom's own, within 250 km over 48 h. Country-level reports and uncorroborated machine-coded events never form one | `ZoneTests` |
| Every outbound request is identical whatever the device position and trusted zones are | `test_requests_are_fixed_and_identical_whatever_the_device_position` |
| The page contacts this origin only, runs one same-origin script, and never parses feed text as markup | `PageTests`, `RouteTests` |
| Feed content is untrusted: entities refused, text bounded and stripped, links only to the publisher's own host | `FeedParsingTests` |
| A failing source loses nothing already held and is named; a malformed feed fails alone | `RefreshTests` |
| Bounded: byte caps per source, 2,500 reports, 72 h retention, 8 GDELT files per run, none fetched twice | `RefreshTests` |
| No score effect, never above `low`, deferrable under load | `WiringTests`, `test_the_job_reports_context_only_never_above_low` |
| A day-on-day trend is offered only after JARVIS has itself collected for two days | `test_a_trend_is_offered_only_after_two_days_of_collecting` |

## Designs compared

| Question | Chosen | Rejected, and why |
|---|---|---|
| Where the fetching happens | The daemon fetches; the page reads `/api/world` | Fetching in the browser: needs a wide CSP, and each publisher sees the owner's browser |
| Conflict event data | Newsroom RSS and channel feeds, plus GDELT's 15 minute event files | ACLED, UCDP: curated and better, but need an account or token (UCDP answered 401, measured). ReliefWeb v1 answered 410. GDELT's GEO API answered 404 |
| Placing a headline | Deterministic match against Natural Earth names | A geocoding service: sends headlines out and returns a confident point for a vague text. A model: not reproducible, and unneeded once precision is carried honestly |
| Globe | three.js on the already vendored, pinned build, as a new page under the strict policy | Adding a layer to the Cesium globe on `/geo`: that page's policy allows a CDN, WebAssembly and tile hosts, and the personal location page should not grow a world news feed |
| Zone shape | Outline of the clustered reports | Filling the country, a heat map: both claim more area than the reports support |

Measured cost on this machine: one refresh is 22 requests and about 20 s of wall time, almost all
waiting on the network (0.5 s of CPU). `/api/world` answers in about 4 ms. Stored state is about
50 kB for 150 reports. The map data is 1.27 MB, served from this origin.

Reconsider if: GDELT positions stay this noisy (then drop the layer), a token for ACLED or UCDP is
available (then use it for zones), or the store write per run grows past a few hundred kB.

## How Jev guided it

`scripts/reviews/world_view_design.py` put 16 candidate moves and 13 things already drawn to Jev
(fixed design metadata only), and ranked them in code.

The first run asked one broad question, "could it mislead or break a rule". It answered between
0.42 and 0.94 for everything, a place search included, so it could not separate candidates. It was
replaced by two narrow questions: does the element present something the data does not contain,
and does it move without new data or load from a third party. The second run is what was acted on.

| Guidance (value; glance / appeal / misread) | What was done |
|---|---|
| Place search 0.47 (0.82 / 0.59 / 0.27) | Built, over the collected reports only |
| Dim everything outside a pinned zone 0.36 (appeal 0.83) | Built |
| Zone bracket pulses only when reporting clearly rose 0.33 | Built, and gated on two days of collecting |
| Per-zone history chart 0.31 | Built |
| Danger level, casualty counts, arcs between belligerents: misread 0.82 to 0.94 | Not built |
| Radar sweep, headline ticker, heat glow, proximity notice: fail the bar or score negative | Not built. The distance to the nearest zone stays as a plain sentence |
| Hover card 0.60, country-level ring 0.36, unverified layer 0.35, zone outline 0.30 | Kept |
| Day/night terminator: misread 0.68, glance 0.16 | Removed |
| Constant slow turn: misread 0.83 | Rotate is now off until switched on |
| Machine-coded events hidden by default 0.65; zone as outline 0.80; open on own position 0.97 | As built |

Not built against a favourable score: tinting a whole country for country-level reports (0.28,
glance 0.29) needs per-country geometry the map file does not carry.

Jev was not used to classify or place reports; that path is deterministic.

## What was verified, and what was not

Verified: 52 unit tests; the real request handler served `/world`, its script, the map data and
`/api/world` over an isolated database; a live refresh against the real sources into that isolated
database (22 of 22 sources answered, 149 reports, all placed); the page rendered in headless Edge
on the GPU path as a globe, as a flat map and with a zone pinned.

Not verified: the scheduled job inside the running daemon, and anything under the sealed release.
Hover, drag, search and replay were not exercised by a human; they were read in code and the
states they lead to were captured through deep links.

Blind spots: the lexicon and the gazetteer are English only. Report volume follows media
attention, not the scale of violence. GDELT positions are unverified. A headline can name a place
that is not where the event happened; the speaking-capital rule catches one common form of that.
Sources are few, and all are large English-language newsrooms.
