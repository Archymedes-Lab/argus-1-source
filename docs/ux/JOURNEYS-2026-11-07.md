# User journeys, 2026-11-07

Method: scenario-based journey maps (NN/g) walked as a cognitive walkthrough. At each
step: will the user know what to do, see the control, understand it, and see the
result? Problems were rated against Nielsen's ten heuristics.
Persona: a non-technical PC owner in Simple mode. The built desktop interface was run
against answers recorded from this PC's daemon (a local mock; the fixtures are private
and not committed). Each step was screenshotted, with the words on screen counted.

## Still open

  reminders included (Urgent 44). Unify the counting in model.ts, both views and tests.
- The finding detail for a category without a guide still says "noticed something" under
  "What this is"; extend guide.json, which is kept in sync in three copies with ten languages.
- Groups such as "Attacker techniques ARGUS-INSTINCT cannot see yet" and "Earlier items that
  came back" are information, not things to act on; consider moving them below the rest.
