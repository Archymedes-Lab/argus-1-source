# Follow-ups found during the restructure

These were kept out of refactor commits on purpose: each one either changes
behavior or needs a decision.

## Detection and reporting

- **`gaps` coverage descriptions for T1090 and T1176.** `hunt.COVERAGE` listed
  both twice. A dict literal keeps the last value, so the gaps report has only
  ever said `implant — proxy, PAC and portproxy` and
  `toolchain / intrusion — software extensions`. The shadowed claims
  (`firewall — proxy and tunnelling`, `intrusion — browser extension
  artefacts`) were dead and have been removed. Decide whether the surviving
  descriptions should name both collectors.
- **Transient alert during the move (2026-09-14 ~22:20).** The running daemon
  had `inputwatch.HOOK_PS1` resolved to `jarvis/win/inputhook.ps1` when
  `jarvis/win/` moved, and it reported "the input-hook helper script is missing
  or unreadable" until it was restarted two minutes later. The ledger shows it
  cleared at the restart. Lesson: restart `jarvis.service` right after any
  commit that moves files, since the daemon runs from this checkout.

## Module size (soft cap about 400 lines)

Each of these needs reading, not mechanical splitting:

- `collectors/telemetry/sysmon_linux.py` (684): `_rules` is 143 lines. Split
  the parsing (`_raw`, `_parse`, `_payload`) from the rules and correlation.
- `collectors/host/spyware.py` (664): the `PS_SPY` payload (152 lines) could
  become `platform/win/spyware.ps1`. `audit_windows` (135) and
  `_keyboard_findings` (89) are separate concerns.
- `collectors/host/posture.py` (584): `audit` is one 307-line function. Split
  it by posture area.
- `collectors/persistence/control.py` (572): the trusted-task verification
  (`_verified_maintenance_task`, `_normalized_text_hash`, `_TRUSTED_IDE_TASKS`)
  is its own concern.
- `collectors/host/intrusion.py` (556): `PS_INTRUSION` (171 lines) plus a
  167-line `audit`.
- `core/vet.py` (556): mostly allowlists and per-kind validators. Splitting
  the data from the validators would be easy.

Moving embedded PowerShell payloads into `platform/win/*.ps1` files must keep
the loaded text byte-identical: some payloads are templated with
`str.replace`. Check each with `scripts/dev/behavior_snapshot.py` plus a direct
comparison of the loaded string.

## Consistency

- About 90 package-internal underscore imports remain (`toolchain/common`,
  `inputwatch/common|helper`, `hidden/common|views`). They're allowed by the
  layer rules. Promote any of them if the package grows a second consumer.
- Import statements regenerated by the move are grouped by target rather than
  sorted. Adding ruff's `I` rule would sort them, but in one large diff that
  should be its own commit.
- The `idx_ind_kind` index (13 MB) may be redundant with `idx_ind_status_seen`
  for the hunt's `kind=? AND status='active'` queries. Check with
  `EXPLAIN QUERY PLAN` before dropping it, since that's a schema change.
